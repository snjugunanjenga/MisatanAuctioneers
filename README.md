## Project Overview
Mistan Auctioneers is a professional auction house specializing in high-end auctions, valuations, and consulting services. This website serves as their digital presence, providing users with information about their services, upcoming auctions, and a way to contact them.

---

## Features
- **Responsive Design**: Fully responsive layout using Bootstrap 5 for seamless viewing on all devices.
- **Multipage Navigation**: Includes pages for Home, About Us, Services, Auction Calendar, Blog, and Contact Us.
- **Interactive Contact Form**: Validates user input and provides feedback.
- **Dynamic Content**: Uses Bootstrap components like cards, grids, and forms for a modern UI.
- **Cross-Browser Compatibility**: Works on all major browsers.

---

## Technologies Used
- **HTML5**: Semantic markup for better structure and accessibility.
- **CSS3**: Custom styling with transitions and animations.
- **Bootstrap 5**: Responsive grid system and prebuilt components.
- **JavaScript**: Form validation and interactivity.

## Deployment

You can deploy this website using any static hosting platform like **GitHub Pages**, **Netlify**, or **Vercel**.

### Steps for Deployment on GitHub Pages:

1. Push the project to a GitHub repository.
2. Go to the repository **Settings**.
3. Enable **GitHub Pages** by selecting the branch and root directory.
4. Access the live site at:  
   `https://<your-username>.github.io/<repository-name>/`
